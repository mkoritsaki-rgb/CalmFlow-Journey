🎈 Floating Thoughts

Κάποιες σκέψεις μένουν μαζί μας περισσότερο απ' όσο θα θέλαμε.
Σήμερα θα τις αφήσουμε να ταξιδέψουν λίγο πιο μακριά.

✍️Τι σκέφτεσαι αυτή τη στιγμή;

Μικρή παύση

Πάρε λίγο χρόνο.

💭 Πώς νιώθεις τώρα;

🌤️ Ας δούμε τη σκέψη λίγο διαφορετικά.

☁️ Ίσως αυτή η σκέψη να μην είναι όλη η αλήθεια.

💙 Δεν χρειάζεται να τα λύσω όλα τώρα.

✨ Μπορώ να κάνω ένα μικρό βήμα κάθε φορά.

🟡 Λίγος ακόμη χρόνος

Φαντάσου τη βροχή.

Οι σκέψεις σου είναι σαν σταγόνες.

Δεν χρειάζεται να τις διώξεις.
Άφησέ τες απλώς να πέσουν απαλά
και να χαθούν στο έδαφος.

Μπορείς να πάρεις λίγο χρόνο.

☀️ Ο ουρανός καθαρίζει

Οι σκέψεις δεν είναι ο ουρανός.
Είναι απλώς σύννεφα που περνούν.
